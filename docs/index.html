THE FINDER WORKFLOW

Three steps to a new format.

  1. Drag a file

    Start from the Desktop or Finder. Select several files to convert them together.

  2. Hold Shift

    See the available output formats. Hold Command during a PDF drag for the tool wheel.

  3. Drop on a format

    The animated lorikeet follows the job. Open the saved copy or reveal it in Finder.

FORMAT GUIDE

What you can convert.

Files stay on your Mac. Some document routes require a separately installed engine.

PDF

PDF tools

Compress image-heavy PDFs for the screen, edit title and author information, reorder pages, split, or merge. Export to Word, text, or page images.

PDFDOCXTXTJPG / PNG
IMG

Images

Convert, resize, and compress photos and screenshots. Preserve PNG pixels during lossless compression or aim for a 500 KB copy.

JPGPNGHEIC*PDF
DOC

Word documents

Save DOCX as PDF with the built-in renderer, or extract text and simple HTML. Add LibreOffice for ODT and more faithful Word layouts.

DOCXPDFTXTHTMLODT*
CSV

Spreadsheets

Turn CSV and TSV into XLSX without losing leading zeros. Export sheets as separate text files or a paginated PDF.

CSVTSVXLSXPDF
TEX

Markdown and LaTeX

Use Pandoc for document export and Tectonic to compile TeX using cached packages.

MD*TEX*DOCX*PDF*

INSTALL OPENLORIKEET

Try it on your Mac.

Use a ZIP from GitHub Releases when one is available, or build from source with Swift 6 and Xcode Command Line Tools. The default package is ad-hoc signed for local testing.

GitHub Releases ↗ Build guide

Build from source

git clone https://github.com/PushkarShah0603/OpenLorikeet.git
cd OpenLorikeet
./scripts/package.sh
open dist/OpenLorikeet.app

Optional engines

  • LibreOffice for Word layout fidelity and ODT export
  • Pandoc for Markdown and LaTeX export
  • Tectonic for cached offline TeX compilation
