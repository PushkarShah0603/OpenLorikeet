# Cartoon lorikeet artwork

`lorikeet-atlas.png` is a transparent four-column, two-row character atlas generated with the built-in imagegen tool. The website uses the identical atlas. Cells, in reading order: alert, blink, curious, working, wings up, wings out, happy/rest, concerned. Runtime frame selection provides expressions and flapping; drawing transforms provide breathing, nodding, and hopping. This is sprite animation with rendered depth, not a rigged 3D model.

Species colour and wing references came from user-supplied lorikeet photographs; those photographs are not distributed here.

Generation prompt: Create a polished animated-movie cartoon rainbow lorikeet desktop mascot, oversized cobalt head, swept feather tuft, expressive warm eyes, curved orange beak, orange/yellow chest, emerald layered wings, teal tail and tiny feet. Soft sculpted feather clumps and cinematic shading, no photorealism or primitive stacked spheres. Exactly four columns by two rows, consistent full-body character, fixed camera, scale and baseline, generous transparent margins. Poses: alert, blink, curious head tilt, focused looking down, delighted wings up, delighted wings sideways, happy wings folding, concerned head tilt. No text, grid, props or shadows.

Extraction prompt: Remove all white/offwhite background to zero-alpha transparency, including feather and foot gaps. Preserve all eight poses, colours, details, positions, sizes, and cell alignment. Keep birds opaque. No painted checkerboard or shadows.
